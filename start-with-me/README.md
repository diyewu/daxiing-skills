# Start With Me｜陪我开始

`start-with-me` 是一个低压力的开工陪伴 Skill。它不会先给你一整套宏大计划，而是把当前任务压缩成一个能够马上执行的第一步，陪你完成一轮短工作，并在结束或暂停时留下清楚的下次入口。

## 功能

- 把模糊、沉重或迟迟无法开始的任务缩成一个具体动作。
- 帮助中断后的任务恢复上下文。
- 在工作中遇到卡点时，继续缩小动作或换一个入口。
- 支持安静、轻柔和稳定三种陪伴方式。
- 支持不计时、固定时长和开放式工作三种节奏。
- 临时想起其他事情时先暂存岔路，再回到当前动作。
- 第一动作完成后，按需提供一个 5–10 分钟的“动量桥”。
- 在完成或暂停时生成可复制的恢复胶囊。
- 可以在保持本轮目标的同时切换到写作、编程等专业 Skill。

## 适合这些情况

- “我知道要做什么，但就是没开始。”
- “这个任务太大，我不知道第一步是什么。”
- “我昨天做到一半，现在接不上了。”
- “陪我工作一会儿，别给我太大压力。”
- “这一步还是做不动，帮我再缩小。”

## 怎么使用

在 Codex 中显式调用 `$start-with-me`，然后告诉它你想推进的任务。

```text
使用 $start-with-me 陪我开始写今天的周报。
```

也可以直接说明希望采用的陪伴方式或时长：

```text
使用 $start-with-me 安静陪我整理演示文稿，我做完第一部分回来。
```

```text
使用 $start-with-me 帮我重新接上昨天中断的方案文档。
```

```text
使用 $start-with-me 陪我工作 20 分钟，第一步尽量小一点。
```

不想回答设置问题时，可以使用快速模式：

```text
使用 $start-with-me，不要问，直接根据上文给我第一步。
```

不希望被时间打断时，可以要求开放式工作：

```text
使用 $start-with-me 安静陪我进入状态，不设结束时间，我做完回来。
```

如果 Codex 已经自动识别到这个 Skill，也可以直接说：

```text
陪我开始。
```

## 一轮对话会发生什么

1. 确认这一轮只推进什么。
2. 定义做到哪里就算够了。
3. 需要时进行一个不超过 30 秒的开工仪式。
4. 给出一个通常能在两分钟内开始的具体动作。
5. 等你用“完成 / 卡住 / 岔路 / 时间到 / 暂停”反馈当前状态。
6. 第一动作完成后再给下一小段；结束时留下恢复入口。

起步卡通常长这样：

```text
这轮只做：完成周报的项目进展部分
第一步：打开周报文档，写下“项目进展”标题
做到这里就算完成：列出三个已经完成的事项
本轮节奏：固定 15 分钟
开工准备：关闭消息窗口，只打开周报文档
回来告诉我：完成 / 卡住 / 暂停
```

## 陪伴方式

- **安静模式**：给出起步卡后不继续打扰，等你回来。
- **轻柔模式**：默认方式，提供简短检查和卡点帮助。
- **稳定模式**：更明确地维护本轮边界，在偏离时帮助回到当前任务。

陪伴方式控制交流语气，工作节奏控制这一轮怎样结束。两者可以自由组合。

## 工作节奏

- **不计时 `untimed`**：默认方式，做到约定结果或主动停止时结束。
- **固定时长 `countdown`**：工作指定时间；时间到只检查进展，不自动算完成。
- **开放式 `flow`**：不设硬停止点，你主动回来时再结束。

指定时长不等于已经创建计时器。只有 Codex 实际调用提醒工具成功后，才会承诺主动提醒。

## 工作中想起别的事

直接发送“岔路：要回复小王”。Skill 会先暂存在当前对话，再带你回到原来的动作：

```text
先放旁边：回复小王
现在回来做：继续写方案第二段
```

默认不会把岔路保存为任务。

## 暂停和恢复

暂停时会生成一张恢复胶囊：

```text
本轮状态：
已经推进：
停在：
下次先做：
需要打开：
```

你可以复制保存；除非明确要求并授权可用工具，否则 Skill 不会自动写入其他地方。

## 能力边界

- 它不是完整的项目管理或长期目标管理工具。
- 它不会因为时间过去就假装任务已经完成。
- 只有真正调用了提醒工具，才会承诺稍后提醒你。
- 默认不会保存任务内容、会话历史或个人偏好。
- 具体技术故障应直接进入排查，而不是强行套用开工陪伴流程。
- 它不会自动关闭应用、屏蔽网站或改变系统设置。

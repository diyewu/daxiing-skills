# Make Codex Pet V2｜把一张角色图孵化成 Codex 动态宠物

## 功能

`make-codex-pet-v2` 会把角色描述、个人头像、原创角色或你有权使用的参考图，做成当前 Codex 可识别的 v2 动态宠物。

它不是只生成一张“像宠物的图”，而是完成整条生产线：

- 建立一张角色身份基准图；
- 生成待机、左右移动、挥手、跳跃、失败、等待、工作、审阅 9 组状态；
- 生成 16 个连续观察方向；
- 将每一帧切成 `192×208`，拼成 `1536×2288` 的 8×11 精灵表；
- 清理色键背景和透明像素；
- 检查空帧、越界、白底、非透明空格和隐藏 RGB 残留；
- 输出总览图、观察方向图、动作 GIF、校验报告和安装包；
- 在用户需要时安装到本机 Codex。

图像生成负责“长什么样、怎么动”，脚本负责“尺寸必须对、空格必须透明、包必须能装”。这两层分开，坏一行时只修一行，不必整套重做。

## 适合这些情况

- “把这张牛来截图做成我的 Codex 宠物。”
- “给我的原创角色做一个 Codex 桌面宠物。”
- “把公司吉祥物做成 8×11 的 Codex v2 spritesheet。”
- “这个宠物精灵表有白底或空帧，帮我修好并验证。”
- “我已经有动作图，只需要切帧、拼图和打包。”

它不适合普通单张插画、Logo、头像，也不负责 Unity、Godot、RPG Maker 等其他精灵表合同。

## 怎么使用

把本目录链接到 Codex Skills 目录：

```bash
ln -s "$(pwd)/make-codex-pet-v2" ~/.codex/skills/make-codex-pet-v2
```

开启一个新 Codex 任务，然后显式调用：

```text
使用 $make-codex-pet-v2，把这张角色图做成 Codex v2 动态宠物，名字叫“大星牛来”。
```

只有文字也可以：

```text
使用 $make-codex-pet-v2，做一只圆滚滚的蓝色水獭 Codex 宠物，戴橙色围巾，风格像软胶玩具。
```

已有精灵表时可以只做修复和验收：

```text
使用 $make-codex-pet-v2，检查这个 1536×2288 的 spritesheet，修复不透明空格并打包成可安装宠物。
```

如果你只想先看文件、不希望写入本机宠物目录，可以说明：

```text
只生成和验证，不安装到 ~/.codex/pets。
```

## 最少要提供什么

二选一即可：

- 一张清晰、尽量全身、主体没有严重遮挡的参考图；
- 一段稳定的角色描述，包括物种、体型、主色、脸部特征和一个容易识别的配件。

最好再提供：宠物名字、想保留的表情、不能改变的细节、是否允许公开分发。

## 会得到什么

完整输出通常包括：

```text
run/
├── pet_request.json
├── final/
│   ├── spritesheet.webp
│   └── validation.json
└── qa/
    ├── contact-sheet.png
    ├── look-directions.png
    ├── review.json
    └── previews/*.gif

package/
├── pet.json
└── spritesheet.webp
```

安装后的目录是：

```text
${CODEX_HOME:-$HOME/.codex}/pets/<pet-id>/
```

`pet.json` 必须包含 `spriteVersionNumber: 2`。v2 精灵表尺寸固定为 `1536×2288`，不是旧版的 `1536×1872`。

## 为什么不是一次生成整张图

一张图里同时塞进 88 个格子，最容易出现角色漂移、漏帧、跨格、白底和动作语义混乱。这个 Skill 先确定角色身份，再按行生成动作，最后用脚本拼图。这样可以先验收待机和右移动，再决定是否继续；某一行坏了，也只重做那一行。

## 依赖

- Codex 的 `$imagegen` Skill：生成基础角色和动作行；
- Python 3；
- Pillow：切帧、透明化、拼图、校验和预览。

没有图像生成能力时，Skill 会保留已经准备好的任务清单和提示词，不会假装完成。你也可以手工提供 11 张符合提示词的横向动作条，再从确定性脚本阶段继续。

## 能力边界

- 角色跨 11 行的一致性仍需要最终视觉检查，不能只看脚本 exit code。
- 图像生成会消耗时间和模型额度；完整 v2 宠物通常需要 1 张基础图和 11 张动作行。
- 非对称文字、徽标、光照和道具可能无法安全镜像，左移行动作需要单独生成。
- Skill 不会绕过图像服务的权限、额度或安全策略。
- 默认不会自动发布到 GitHub、公众号或其他平台。
- 未明确要求安装时，生成文件不会写入 `~/.codex/pets`。

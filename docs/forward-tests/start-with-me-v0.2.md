# start-with-me V0.2 隔离前向测试报告

## 测试结论

- 测试日期：2026-08-11
- 测试对象：安装在 `/Users/wudiye/.codex/skills/start-with-me` 的 V0.2 干净副本
- 测试方式：每个场景使用一个全新隔离 Agent，仅提供 Skill 路径和用户原始请求，不提供预期答案或诊断结论

## 判定口径

每个输出同时检查：是否命中正确工作流、第一动作是否足够小、是否尊重用户指定节奏、是否只依据可观察事实、是否虚构计时或持久化能力，以及是否维持低压力的表达方式。

## 场景 8 修订

首次输出把长期规划请求带入了需求收集，并声称后续会建立长期跟踪，容易让用户误以为 `start-with-me` 自己具有持久化任务管理能力。V0.2 随后增加三条明确约束：

1. 完整规划和长期任务跟踪请求不得启动开工陪伴流程；
2. 有合适工作流时路由，无合适工作流时先说明边界并询问是否切换；
3. 不得在 `start-with-me` 名义下承诺计划、持久化、长期跟踪或未来回访。

同步更新了 `scenario-playbook.md` 的完整规划场景和静态契约测试。新的隔离 Agent 复测能够先声明边界，再建议切换到产品规划和 TaskRadar Web 工作流，未声称本 Skill 已经建立跟踪。

## 最终验收

16 个隔离场景均满足 V0.2 的核心契约。干净安装副本可以处理开始、缩小、安静陪伴、开放节奏、时间到、岔路、恢复、跨 Skill 协作和无持久化回执，同时能把技术排查、完整规划与长期任务管理请求导向更合适的工作流。

# make-codex-pet-v2 评估记录

## 基本信息

- Skill 名称：`make-codex-pet-v2`
- 当前阶段：已验证
- 最后更新：2026-08-17
- 评估对象：Codex 自定义动态宠物 v2 工作流；参考本机 Apache 2.0 许可的 `hatch-pet` 实现，并以当前 Codex 桌面应用的实际加载合同校正。

## 评估结论

值得开发。参考实现已经证明“图像生成负责角色与动作，确定性脚本负责切帧、透明化、拼图和校验”的分层可行，但它的公开合同停留在 8×9。当前 Codex 应用同时支持 v1 和 v2，v2 使用 8×11、1536×2288，并新增 16 个观察方向。本 Skill 重新定位为中文友好的 v2 宠物生产线，交付可安装宠物、质检图和可审计报告，不绑定“牛来”或任何单一角色。

## 定位与用户需求

- 一句话定位：把角色描述或参考图孵化成可安装、可验证的 Codex v2 动态宠物。
- 目标用户：希望把个人头像、原创角色、品牌吉祥物或同人形象放进 Codex 的创作者和开发者。
- 核心需求：角色身份跨 11 行保持一致，精灵表几何、透明背景、空单元格和包结构严格符合应用合同。
- 成功结果：生成 `pet.json`、`spritesheet.webp`、校验 JSON、总览图和动作预览，并能被当前 Codex 识别。

## 触发场景与边界

### 应触发

- “把这张角色图做成 Codex 宠物。”
- “生成一个 8×11 的 Codex v2 spritesheet。”
- “修复这个宠物精灵表的透明背景或空帧。”
- “验证并打包现有 Codex 宠物。”

### 不应触发

- 普通单张插画、Logo、头像或表情包生成。
- 与 Codex 宠物合同无关的 Unity、Godot、RPG Maker 等精灵表。
- 用户无权使用且要求规避第三方权利的角色素材。
- 仅需要介绍 Codex 宠物概念而不生成、修复或验证文件的问答。

## 重构决策

### 保留

- 基础角色图 → 分行动作图 → 确定性切帧与拼图 → 自动校验 → 视觉质检 → 打包的分层机制。
- 192×208 单元格、8 列、按状态固定帧数和空白单元格透明的低自由度合同。
- 色键背景选择、逐帧透明像素归零、最小范围修复和动作 GIF 预览。

### 重建

- 从 v1 的 8×9 重建为 v2 的 8×11，并加入 16 个观察方向。
- 触发说明、中文 README、安装示例、输出合同和用户风险提示。
- 将品牌研究、图像生成、文件写入和最终安装拆成清楚的授权边界。
- 以当前应用二进制的宽高和 `spriteVersionNumber` 解析结果作为本轮合同证据。

### 删除

- 强制使用子 Agent 的运行前提；Skill 可单 Agent 顺序执行，也可在用户允许时并行。
- 与特定来源宠物、品牌或角色绑定的命名、示例和公共身份。
- 无法由脚本或视觉检查验证的“自动完美一致”承诺。

## 规划内容

核心流程为：确认权利与角色身份 → 准备运行目录和 12 个图像任务（1 个基础图、11 行）→ 用 `$imagegen` 逐项生成 → 切帧与透明化 → 生成 1536×2288 atlas → 自动校验 → 检查总览和预览 → 最小范围修复 → 写入 v2 `pet.json` 并安装。运行包包含 8 个确定性 Python 脚本、3 份按需 reference、用户 README、UI 元数据和 Apache 2.0 许可说明。

## 版本范围

### 当前版本包含

- Codex v2 8×11 合同。
- 9 个任务状态和 16 个观察方向。
- 参考图或纯文字起稿。
- 色键去背景、切帧、拼图、校验、总览和 GIF 预览。
- 本地 `${CODEX_HOME:-$HOME/.codex}/pets/<pet-id>/` 打包。

### 当前版本不包含

- 绕过图像生成服务的授权、额度或安全策略。
- 第三方角色、商标或肖像的版权清理。
- 自动发布 GitHub、公众号或应用商店。
- 100% 自动保证跨行角色一致；最终视觉质检仍是验收门槛。

## 风险与约束

- 11 行图像生成成本较高，必须先用基础图、idle 和 running-right 验证身份与动作方向。
- 模型可能复制布局辅助线、产生白底、跨格、裁切或角色漂移，自动几何验证不能替代视觉检查。
- 非对称文字、徽标和道具不适合直接镜像 running-left。
- 同人角色公开分发需单独确认权利；开源许可证只覆盖本仓库原创代码和明确授权的素材。
- 安装到 `~/.codex/pets` 会写入用户环境，必须在文件生成和验证完成后再执行。

## 验收场景

1. 使用一张角色参考图生成完整 v2 宠物，校验宽高、11 行、空单元格、透明像素和 v2 manifest。
2. 仅用文字描述生成基础形象，再完成 11 行任务。
3. 对 1536×2288 现有 spritesheet 运行验证并给出具体坏单元格。
4. 输入普通单张插画需求时不误触发。
5. 图片生成不可用时停止在已准备的任务清单，不伪造行图或完成状态。
6. 用户未授权安装时只交付文件，不写入 `~/.codex/pets`。
